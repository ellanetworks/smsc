**Ella SMSC** lets private cellular network subscribers send and receive SMS messages. It is an SMS Service Center (SMSC) that integrates with 4G and 5G core networks.

[Get Started Now!](https://docs.ellanetworks.com/smsc/tutorials/first_sms/)

## Key Features

- SMS over 4G and 5G, through the MME or SMSF (SGd), with routing from the HSS (S6c)
- SMS over IP, through an IP-SM-GW
- Store and forward: retries, validity periods, and delivery as soon as a phone is reachable again
- Status reports
- Application messages over the HTTP API
- Embedded database (SQLite)
- Web UI and HTTP API
- Prometheus metrics
