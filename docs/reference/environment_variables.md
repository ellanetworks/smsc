# Environment Variables

These environment variables override parameters of the configuration file.

| Variable | Overrides |
| -------- | --------- |
| `SMSC_DIAMETER_HOST_LABEL` | `diameter.host_label` in the [configuration file](config_file.md) |
| `SMSC_CLUSTER_ADVERTISE` | `cluster.advertise` in the [configuration file](config_file.md) |
