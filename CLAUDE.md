# Ella SMSC - AI Coding Agent Instructions

## Code Comments

**Write zero comments.** Do not add explanatory comments, section headers, TODOs, or doc comments to any code you write or modify — not even for non-obvious logic. The only exception is a comment the linter or compiler requires (e.g. `//nolint:` directives, `//go:generate`, `//go:embed`, build tags, or an exported-symbol doc comment that `golangci-lint run ./...` fails without).

**Do not touch existing comments**, with one exception: if an existing comment is factually incorrect after your change, fix it or delete it. Never reword, reformat, expand, or "improve" a comment that is already correct, and never delete a correct comment.
